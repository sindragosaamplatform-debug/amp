# Як запустити (5 хвилин)

Прототип бота підтримки: відповідає командам партнерських програм за статтями
довідкового центру help.aff.ltd і завжди дає посилання на статтю.

Найпростіший спосіб подивитися — через **Claude Code**. Свій API-ключ не
потрібен: базу знань підключено як MCP-сервер, а клієнтом виступає сам Claude
Code.

## Що потрібно

- macOS або Linux
- Claude Code ([інструкція зі встановлення](https://claude.com/product/claude-code))
- Python 3.8+ — на macOS уже є, перевірити: `python3 --version`

## Кроки

**1.** Розпакувати архів у будь-яку папку, наприклад `~/aff-support-bot`.

**2.** Відкрити Claude Code саме в цій папці:

```bash
cd ~/aff-support-bot && claude
```

**3.** Claude Code побачить у папці файл `.mcp.json` і запитає дозвіл підключити
MCP-сервер `aff-kb` — підтвердити. Це локальний скрипт, який просто читає
текстові файли з бази знань, нікуди нічого не надсилає.

**4.** У чаті ввести:

```
/aff-support
```

**5.** Далі просто питати як клієнт, будь-якою з трьох мов:

- Не бачу промо-лендінги в кабінеті, що робити?
- Как подключить постбек в Keitaro?
- Що таке hold і коли зарахується FD?

Бот знайде потрібну статтю, прочитає її цілком і відповість кроками з
посиланням на статтю.

## Що всередині

2547 записів у двох джерелах:

| Розділ | Записів | Про що |
|---|---|---|
| `admin-panel` | 50 | Інструменти клієнта — основне джерело відповідей |
| `aff-area` | 15 | Кабінет вебмайстра — що клієнт налаштовує своїм партнерам |
| `additional-resources` | 3 | Додаткові матеріали |
| `team-cases` | 2479 | Реальні запити команд до платформи AMP (внутрішнє) |

Перші три — статті довідкового центру, на них бот посилається. `team-cases` —
вивантаження робочих чатів: бот використовує їх як контекст, але не переказує
ситуацію однієї команди іншій. Ідентифікатори
(e-mail, IP, ID партнерів, Jira, ніки) з них вирізані на етапі імпорту.

## Якщо не запустилося

**MCP-сервер не стартує.** Найімовірніше Claude Code запускає його не з тієї
папки. Відкрити `.mcp.json` і замінити відносний шлях на повний:

```json
{
  "mcpServers": {
    "aff-kb": {
      "command": "python3",
      "args": ["/повний/шлях/до/aff-support-bot/kb_mcp.py"]
    }
  }
}
```

**Перевірити базу без Claude Code** — має вивести кількість записів:

```bash
python3 kb.py
```

**Перевірити пошук:**

```bash
python3 kb.py search "постбек keitaro"
```

## Межі прототипу

- Відповідає **тільки** за статтями довідкового центру. Немає статті — каже про
  це прямо й пропонує передати питання менеджеру.
- Не знає, хто саме питає: баланс, статус оферу, персональні дані — поза базою.
- Не обіцяє виплати, ставки й рішення по акаунтах.
- База — зріз на момент вивантаження. Оновлення статей: `python3 scrape_help.py
  --url https://help.aff.ltd/uk/aff-area --out kb-uk/aff-area --keep-images`;
  оновлення кейсів: `python3 ingest_cases.py <новий CSV>`

Технічні деталі архітектури — у [README.md](README.md).

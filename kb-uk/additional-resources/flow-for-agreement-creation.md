# Флоу підписання договору
URL: https://help.aff.ltd/uk/additional-resources/flow-for-agreement-creation
Category: Додаткові матеріали
Section: Договори та IO
Summary: Особливості підписання договору та роботи з юр. відділом.
Updated: 8 місяців тому

Для складання договору партнеру потрібно через тікет надіслати інформацію про свою компанію. Компанія має бути зареєстрована за межами СНД (ФОП може бути зареєстрований у СНД). У картці повинні бути зазначені:

1. Назва компанії (ФОП)
2. Юридична адреса, країна реєстрації
3. Види діяльності компанії (ФОП)
4. Ім’я, прізвище, посада підписанта
5. VAT / без VAT (лише для компаній)

Після отримання інформації від партнера створюємо задачу в Jira у категорії LAW.
Алгоритм, якому слід дотримуватися при створенні задачі для контрактного відділу юридичного департаменту, описано в Документації (https://wiki.syneforge.com/pages/viewpage.action?pageId=305585086&flashId=1023992901).

Після підписання договору обома сторонами:

- відправляємо партнеру копію;
- додаємо в нотатки акаунта партнера посилання на задачу з договором в Jira;
- активуємо чекбокс "Виплати Wire Transfer" в Профілі партнера;
- можемо починати виплати за інвойсами.

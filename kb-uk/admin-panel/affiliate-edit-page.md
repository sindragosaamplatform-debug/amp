## 1. Таб "Редагування"

Для табу РЕДАГУВАННЯ додано якір #edit. URL табу → /admin/new/webmasters/profile/NNNNNN#edit

Таким чином, є можливість пересилати посилання на конкретну вкладку сторінки "Профіль".

Таб РЕДАГУВАННЯ розділений на блоки: "Про партнера", "Нарахування та безпека", "Додаткова інформація", "Системні налаштування", "Реферали". У кожному блоці виведено окремі параметри для редагування.

2. Опис блоків та параметрів

## 2.1. Блок "Про партнера"

- "Основний Email" (обов’язкове поле) – основний email партнера, використовується для авторизації в кабінет партнера та отримання розсилок на цю адресу. За замовчуванням додається email, зазначений під час реєстрації партнера. Праворуч від поля відображається статус підтвердження email, статус можна змінити.

Статуси email партнера:

1. Підтверджений – партнер перейшов за посиланням із листа, надісланого під час реєстрації.
2. Не підтверджений – лист партнеру було надіслано, але партнер НЕ перейшов за посиланням із листа. Це обмежує можливість входу в К/В.
3. Лист надіслано – лист партнеру було надіслано. Статус очікування підтвердження пошти. Це обмежує можливість входу в К/В.
4. "Додатковий Email" – додатковий email партнера, необхідний у разі втрати партнером доступу до свого кабінету. Поле використовується під час заміни email для партнера.

Якщо значення для поля заповнено, відображаються опції використання додаткової пошти:

1. Для авторизації та відновлення пароля – при активному чекбоксі авторизація партнера здійснюється тільки через додатковий email.
2. Для отримання сповіщень про тікети та заходи – при активному чекбоксі всі сповіщення партнер отримуватиме на додаткову пошту.

[image: https://ucarecdn.com/d2c7a278-ebbc-4c3a-9059-fb28b16f7eb2/image.png]

Якщо у партнера заповнене поле з додатковою поштою, його можна знайти за додатковим email на сторінці "Партнери".

- "Контакт" (обов’язкове поле) – поле редагування Telegram, Skype та/або інших месенджерів контакту. Одне з полів має бути заповнене. За замовчуванням вказаний контакт, зазначений під час реєстрації.
- "Телефон" – номер телефону партнера. За замовчуванням вказаний номер, який зазначався під час реєстрації.
- "Affowner" – технічна мітка, яка означає належність партнера до конкретної партнерки та/або менеджера. Налаштування Affowner для партнера.
- "Група" – налаштування Групи для партнера. За замовчуванням вказана група, до якої партнер потрапляє під час реєстрації.

2.2. Блок "Нарахування та безпека"

- "Тип партнера" – налаштування типу партнера:

○ Tech-партнер
○ Mediabuyer

- "Нарахування доходу" – активує/деактивує нарахування доходу партнеру.
- "Реферальні нарахування" – активує/деактивує реферальні нарахування партнеру.
- "Магазин (AffPartners_v1 Shop)" – активує/деактивує відображення Магазину в головному меню К/В (тільки для AffPartners_v1).
- "Нарахування балів (AffPartners_v1 Shop)" – активує/деактивує нарахування балів партнеру.
- "Ремаркетинг" – налаштування нарахувань за гравців, перенаправлених через ремаркетинг. Активує/деактивує можливість фіксації трафіку за партнером за умови, що гравець із казино A зареєструвався за банером ремаркетингу в казино B (з даними з казино A). Актуально тільки для проєктів групи SMEN. Партнер може отримувати дохід із казино B за RevShare.
- "Доступ за IP" – налаштування активації/деактивації доступу в К/В за дозволеними IP.
- "IP для авторизації" – поле введення дозволених IP для входу.

Якщо є додані IP (додані партнером або адміністратором), вони відображаються нижче поля для введення IP.

За дозволеними IP партнер може авторизуватися в К/В. І тільки за ними!

Якщо IP немає – це означає, що доступ дозволений з будь-якого IP.

- "Зміна реквізитів партнером" – налаштування активації/деактивації автоматичного розблокування виплат після підтвердження через email.

2.3. Блок "Додаткова інформація"

- "Новинна Email розсилка" – якщо відключити чекбокс, партнер не отримуватиме новинну розсилку на email.
- "Email-сповіщення по тікетах + системні листи" – якщо відключити чекбокс, партнер не отримуватиме розсилку щодо тікетів на email, включно зі сповіщеннями про відновлення пароля.
- "Використовує API реєстрації" – відображені ключі віддаленої авторизації партнера.
- "Sub_ID limit" – налаштування ліміту створених sub_id (динамічних рефкодів) для партнера.

Під полем відображається кількість sub_id (створених динамічних рефкодів), які партнер використовує на цей момент.

2.4. Блок "Системні налаштування"

- "Тема кабінету" – налаштування зміни теми К/В у партнера. Змінювати лише у разі необхідності.
- "Виведення статистики Action/Entry" – налаштування відображення статистики в К/В, вибір Action або Action + Entry для партнера (можливість показу Entry FD або Entry Reg).
- "Завантаження таблиці статистики" – налаштування формату завантаження таблиці статистики в К/В. Автоматично або За кнопкою.
- "Вибрана валюта" – вибрана валюта для відображення статистики в К/В.
- "Деактивація профілю" – налаштування блокування партнера.

Поле "Причина блокування/розблокування" є обов’язковим.

Перед натисканням на кнопку "Зберегти" необхідно переконатися в розумінні та усвідомленості прийнятих дій. Якщо є сумніви – краще уточнити у свого ліда або звернутися в профільний чат із платформою.

2.5. Блок "Реферали"

- "Джерело залучення" – джерело залучення реферала.
- "Реферал для" – рефовод-партнер реферала.

3. Флоу для заміни пошти

## Нову пошту, за наявності запиту через тікет, необхідно вставити в поле "Додатковий Email" та натиснути "Зберегти".

Після збереження змін автоматично активуються такі чекбокси:

- Для авторизації та відновлення пароля;
- Для отримання сповіщень про тікети та заходи.

Початкова (основна) електронна пошта партнера залишається як логін, але за її допомогою більше неможливо увійти до К/В або скинути пароль.

Під час редагування не змінюємо "Основний Email" партнера!

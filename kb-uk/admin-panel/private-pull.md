## 1. Общая информация

Функционал Private-пул позволяет направлять трафик на приватный пул зеркал, который будет использоваться только для конкретного партнера или группы партнеров.

В выделенном пуле находится несколько зеркал. Таким образом, если одно зеркало банится, трафик будет идти на другие, которые стоят в ротации для пула.

Набор выделенных доменов проверяется на доступность из-под игроков (с помощью пингов), зеркала автоматически ротируются.

Использование Private-пулов позволяет избежать потери трафика (по сравнению с использованием схемы трафика на 1 зеркало).

## 2. Создание и Редактирование Private-пула

2.1. "Private-пул" для каждого продукта расположен на странице "Список сайтов", справа от кнопки "ГЕО-пул".

[image: https://d295evyo48.ucarecd.net/2d320f4f-1996-4daf-b329-01cac020f932/Group_14.png]

Путь → /admin/site_private_domains/list/NNN

2.2. Private-пул по умолчанию нигде не используется, его зеркала не привязаны к странам.

Private-пул может использоваться только в Схемах трафика для партнера, группы партнеров и/или ПП.

2.3. Добавление Private-пула

Private-пул создаётся на странице "Private-пул" для конкретного бренда.

Например:

- Для продукта переходим на страницу Private-пул, кликнув рядом с сайтом кнопку "Private-пул".

[image: https://d295evyo48.ucarecd.net/673c8776-6534-4243-9153-7acab81c7e4a/Group_14.png]

- Нажимаем кнопку "Создать Private-пул".
- Вводим название для Private-пула. Например: "107074, 83322 (Уругвай)".

Название пула должно быть информативным и соответствовать характеристике схемы. Необходимо указывать ID партнёров, тип трафика или ПП + страну, под которые создаётся пул.

[image: https://d295evyo48.ucarecd.net/bead2404-e925-4ffd-8dd0-09b1c62a7100/Group_15.png]

- В блоке "Зеркала" добавляем зеркало. Например: besttest9.com → нажимаем "Добавить".

[image: https://d295evyo48.ucarecd.net/f50f80f6-4f92-4e6e-bcd1-c7b91152bf4a/Group_16.png]

При создании Private-пула можно сразу добавить несколько разных зеркал.

[image: https://d295evyo48.ucarecd.net/4fc4a042-adeb-436e-89a3-11157120b4a1/image.png]

[image: https://d295evyo48.ucarecd.net/d4d4b850-d265-47ed-97ac-afeb42e0e6b1/image.png]

Добавление нескольких зеркал доступно через запятую, через пробел или с новой строки.

- Нажимаем на кнопку "Сохранить". Кнопка выводится после добавления зеркал.

Теперь Private-пул успешно создан.

Для ротации зеркал в Private-пул необходимо, чтобы было 3 зеркала.

Поиск нужного Private-пула осуществляется по названию или по добавленным зеркалам.

2.4. Редактирование и блокировка зеркал в рамках Private-пул

Private-пул можно отредактировать. Есть возможность замены набора зеркал или названия.

Зеркала из Private-пула можно удалить или заблокировать.

Если зеркало заблокировано, то нажимаем кнопку "Заблокировать".

[image: https://d295evyo48.ucarecd.net/ada3f551-a2f2-484e-ae91-bfdcd7202569/Group_17.png]

Если зеркало было ошибочно добавлено или его просто надо убрать из Private-пула, то нажимаем кнопку "Удалить".

Невозможно удалить зеркало, которое используется по умолчанию или в ротации. Зеркало нужно сперва отправить в беклог, затем его можно удалить.

Зеркало по умолчанию невозможно заблокировать – необходимо другое зеркало выбрать "По умолчанию", а только потом заблокировать исходное.

## 3. Схема трафика на Private-пул

3.1. При создании схем трафика (по партнеру/по партнерской программе/по группе партнеров) есть возможность настроить схемы трафика по Private-пулам.

Схемы задаются на странице Схемы трафика: /admin/tds_traffic_scheme

Для выбора доступны стратегии:

- blind redirect на дефолтное зеркало Private-пула (используем только эту стратегию);
- полный перегон трафика на Private-пул;
- переход со страницы редиректора на Private-пул.

[image: https://ucarecdn.com/6a30f544-9b2b-4450-a721-a70b75e46438/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-10-12%20%D0%B2%2014.50.05.png]

После выбора одной из стратегий – проставляем сайт, Private-пул и программу (программа – опционально, можно без неё).

Для настройки схемы по Private-пулу обязательно выбираем стратегию: Blind redirect на дефолтное зеркало Private-пула.

Выбор пула и программы будет доступен после выбора сайта.

Для "Private-пул зеркал" выводится список Private-пулов, созданных для выбранного сайта.

Среди предложенного списка выбираем нужный Private-пул, на который будет направлен трафик по схеме.

[image: https://ucarecdn.com/77beb4b0-95e1-48ca-bb6e-38981f081809/screencast 2023-12-14 16-01-39.gif]

3.2. Описание стратегий

Blind redirect на дефолтное зеркало Private-пула – происходит пинг зеркал Private-пула и игрок попадает на первое, которое ответило. При недоступности всех зеркал пользователь будет перенаправлен на зеркало, которое указано по умолчанию в Private-пуле (этот параметр указывается в списке зеркал Private-пула).

Полный перегон трафика на Private-пул – пользователь будет сразу перенаправлен на зеркало, которое указано по умолчанию в Private-пуле (этот параметр указывается в списке зеркал Private-пула).

Переход со страницы редиректора на Private-пул – после пингов зеркал Private-пула пользователь будет перенаправлен на зеркало, которое указано по умолчанию в Private-пуле (этот параметр указывается в списке зеркал Private-пула).

Всегда при работе с Private-пулом выбираем стратегию: Blind redirect на дефолтное зеркало Private-пула.

3.3. Общая логика и нюансы

При выбранном редиректе на пул зеркал трафик направляется на зеркала в ротации указанного Private-пула.

Система пингует зеркала в ротации и перенаправляет игрока на доступное для него.

Если все зеркала пула не отвечают – игрок будет отправлен на дефолтное зеркало.

- Если Private-пул зеркал удаляется – схема трафика деактивируется.
- Если схема была настроена на несколько Private-пулов, то при удалении одного Private-пула – аналогично отключается вся схема.

○ Выбирать один и тот же Private-пул можно для нескольких схем трафика.
○ Если для Private-пула меняется название – схема трафика продолжит работать. Название пула поменяется и для схемы.

3.4.1. Редактирование схемы трафика, если нужно изменить страну (например).

- На странице Схемы трафика находим нужную схему и нажимаем "Редактировать".

[image: https://d295evyo48.ucarecd.net/f344e2b0-8e1c-428e-ae3a-d24ac9d86137/image.png]

- Для схемы выбираем страну.

[image: https://d295evyo48.ucarecd.net/3df40a82-958a-4ae5-80cb-2a3ddf620503/image.png]

- Нажимаем кнопку "Сохранить" и получаем оповещение об успешном сохранении изменений.

[image: https://d295evyo48.ucarecd.net/a59d8d04-736f-46b5-b48d-f8b54e65f445/image.png]

3.4.2. Если уже была создана схема трафика на 1 зеркало и её надо перевести на Private-пул.

После создания Private-пул нужно изменить имеющуюся схему трафика и перенаправить её на Private-пул.

- На странице Схемы трафика нужно найти схему, которая создавалась на выделенное зеркало из Дефолтного пула. В данному случае vulkanvegas9.com

[image: https://d295evyo48.ucarecd.net/6492e2e1-3ec3-4e3d-88c5-0337b6ea66fb/image.png]

- Предварительно удаляем имеющуюся стратегию.

[image: https://ucarecdn.com/73a2f43c-1daf-4b60-95d4-0852bf3aba57/Снимок экрана 2023-11-30 в 14.28.13.png]

- Создаём новую стратегию: Blind redirect на дефолтное зеркало Private-пула.

[image: https://ucarecdn.com/476ddd6c-7fea-4487-8452-f169738aec3b/Снимок экрана 2023-11-30 в 14.20.28.png]

- Нажимаем кнопку "Сохранить". Все действия выполняем в указанной последовательности.

После изменения схемы трафика с зеркала на Private-пул необходимо удалить само зеркало из Дефолтного пула.

Необходимо написать команде поддержки AMP.

# Функціонал сторінки "Менеджер за замовчуванням"
URL: https://help.aff.ltd/uk/admin-panel/default-manager
Category: ⚙️ Адмін-панель
Section: Адміністратори
Summary: Опис функціоналу сторінки "Менеджер за замовчуванням". Додавання адміністратора в розподіл партнерів за партнерською програмою.
Updated: 9 місяців тому

Сторінка "Менеджер за замовчуванням (https://aff.ltd/admin/Settings/affiliateProgramAffiliateManagers)" призначена для керування розподілом партнерів за партнерськими програмами – тобто для налаштування, на якого менеджера будуть призначатися нові партнери.

Сторінка знаходиться в меню "Користувачі" → "Менеджер за замовчуванням".

На сторінці відображається список партнерських програм і менеджерів, призначених для автоматичного розподілу партнерів.

- У стовпці "Менеджер" зазначається наявність призначених ведучих менеджерів для партнерських програм.
- Порядок розташування менеджерів у списку впливає на черговість розподілу нових партнерів.

Приклад:
Якщо для партнерської програми призначено 4 менеджери, а зареєструвалося 10 партнерів, партнери по черзі будуть закріплені за кожним наступним менеджером. Система розподілить їх по колу – 1 → 2 → 3 → 4, потім знову 1 → 2 → 3 → 4.

[image: https://d295evyo48.ucarecd.net/0435c35b-bc5d-48de-b475-cb554a109be8/image.png]

Якщо потрібно, щоб за партнерами не закріплювався конкретний менеджер, активуйте чекбокс "Менеджер не встановлений".

[image: https://d295evyo48.ucarecd.net/9c914de8-a1c2-4234-91ba-331b2fa19d76/Screenshot_2025-10-29_at_13.01.00.png]

Якщо менеджер(и) не вибрані, партнери будуть розподілені випадковим чином між усіма менеджерами, доступними для партнерської програми. У полі для введення при цьому відобразиться значення "Випадковий".

[image: https://d295evyo48.ucarecd.net/2edc1e93-baab-41f4-a846-f79cbc19b960/image.png]

Після вибору або зміни налаштувань ведучого менеджера для партнерської програми натисніть кнопку "Зберегти", щоб застосувати налаштування.

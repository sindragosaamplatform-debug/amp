### 1. Загальна інформація

Посилання на сторінку: https://aff.ltd/admin/new/offers-templates

Розташування: "Управління" → "Шаблони оферів".

Сторінка надає інструменти для додавання та налаштування шаблонів оферів, доступних для видачі партнерам.

Адміністратор може додавати нові шаблони, змінювати умови оферів, встановлювати офер за замовчуванням для п/п. Також доступний експорт умов за виданими кастомними оферами.

[image: https://d295evyo48.ucarecd.net/7303a8a4-4a3b-46e2-891a-9e5dd183f446/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA_%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0_2025-12-11_%D0%B2_15.13.12.png]

1.1. Структура сторінки

- Кнопка "+ Додати шаблон офера"
- Кнопка "Експорт"
- Фільтри: "Партнерська програма", "Бренд", "Тип офера", "Шаблон"
- Таблиця з картками шаблонів оферів

Сортування в таблиці встановлено за датою зміни (зміною вважається будь-яке редагування офера).

### 2. Картки шаблонів оферів

Картка відображає основну інформацію про умови налаштованого шаблону оферу.

[image: https://d295evyo48.ucarecd.net/18364d0a-345d-4751-8d78-2b77a05c2214/AMP_-_Offers_Templates_2025-12-11_15-14-39.png]

2.1. Структура картки

Структура картки наслідує структуру зі сторінки "Офери" партнера.

- Заголовок (складається з ID + назви в адмін-панелі + бренду)
- Партнерська програма (або декілька п/п)
- Група партнерів, для якої доступний шаблон
- Валюта офера
- Логін адміністратора, який створив або востаннє відредагував шаблон
- Дата створення шаблону
- Кнопки дій:
○ Редагувати
○ Видалити
○ Видані офери – список виданих оферів за шаблоном для партнера/групи партнерів
○ Історія – історія змін шаблону

Якщо для шаблону встановлено тег "За замочуванням" – це дефолтний офер для п/п.

[image: https://d295evyo48.ucarecd.net/92ec508e-d092-415a-a35a-e84fa8779ab3/image.png]

2.1.2. В "Базових умовах" відображаються вимоги, задані в межах обраного типу офера: RevShare, Dynamic RS, CPA і CPFD, Dynamic CPA і CPFD, Hybrid.

Для шаблону Fiхed-оферів відображаються лише назва, п/п та/або група партнерів, логін адміністратора, дата створення і кнопки дій (без кнопки "Видані офери").

### 3. Створення / Редагування шаблонів оферів

3.1. Форма додавання шаблону

Якщо в розділі "Офери" партнера немає відповідного офера (наприклад, потрібен окремий CPA-офер під конкретний застосунок або джерело трафіку), необхідно створити новий шаблон офера.

Додавання шаблону відбувається на окремій сторінці, яка відкривається після натискання кнопки "+ Додати шаблон офера".

URL → https://aff.ltd/admin/new/offers-templates/create

[image: https://d295evyo48.ucarecd.net/0334e25f-01ae-455f-aae8-015207cda1da/AMP_-_Offers_Templates_2025-12-11_15-21-22.png]

Послідовність заповнення полів:
Бренд → Тип оферу → Назва шаблону (англійською мовою).

Після вибору бренду з’являється блок "Партнерська програма" – він відповідає за вибір п/п для шаблону офера.
У цьому ж блоці задаються параметри "За замовчуванням" та "Валюта" шаблону.

[image: https://d295evyo48.ucarecd.net/39125032-4969-4bcd-b8f7-91fa264a2642/screencast_2025-12-11_15-19-18.gif]

Чекбокс "За замовчуванням" не чіпаємо. Він має бути вимкнений.

Група партнерів – функціонал дозволяє обрати групи партнерів, для яких цей офер буде доступний.

У "Базових умовах" задаються вимоги в межах створеного типу оферу.

Базові умови та умови Кваліфікації/Декваліфікації в наповненні форми додавання шаблону залежать від типу оферу, що налаштовується.
Відмінності полягають у наборі полів, які відображаються для задання умов.

Шаблон Fiхed-оферів – додаткові поля нижче налаштувань "Партнерська програма" та "Група партнерів" НЕ відображаються.

Заповнення полів базових умов необхідне на випадок, якщо офер потрібно зробити дефолтним для п/п (активований чекбокс By default).

У такому разі в к/п відобразиться цей офер із заданими умовами.

3.1.1. Значення за замовчуванням для умов шаблону

- Відсоток RevShare, CPA ставка, Спіни, Депозити – 0
- Бейслайн – 0,1

Значення для ставки можна задати лише у випадку, якщо шаблон оффера є дефолтним для однієї з партнерських програм.

Кваліфікація/Декваліфікація

- Дні для кваліфікації від реєстрації – 7
- Дні до автореджекту – 90
- Дні для кваліфікації від FD (0–30) – 0
- Розраховувати CPA за EntryMonth – false
- Рівень деквали – 0, декваліфікація вимкнена.

3.1.2. Кнопки дій

У нижній частині сторінки відображаються кнопки "Додати декілька" та "Додати один".

- Додати один – додається один шаблон оферу із заданими налаштуваннями.
- Додати декілька – відкривається модальне вікно з вибором кількості шаблонів (1–10).
Після підтвердження додається вказана кількість шаблонів офера з однаковими налаштуваннями.

[image: https://d295evyo48.ucarecd.net/e6971298-ec60-42a7-9557-f6230b86d9bc/AMP_-_Offers_Templates_2025-12-11_15-26-41.png]

Якщо створюється кілька шаблонів, до назви послідовно додається порядковий номер, наприклад: "Шаблон 1", "Шаблон 2" тощо.

Для шаблонів оферів, позначених як "За замовчуванням", неможливо додати кілька шаблонів.

Після додавання шаблону – офер стає доступним для видачі в розділі "Офери" для партнера.

3.1.3. Якщо під час додавання шаблону оферу обрано значення "За замовчуванням", і при цьому для п/п уже існує шаблон за замовчуванням, попередньо відображатиметься модальне вікно підтвердження дії.

[image: https://d295evyo48.ucarecd.net/a16a8924-45ed-457b-ab7a-6ebbb85b0755/AMP_-_Offers_Templates_2025-12-11_15-28-52.png]

3.2. Форма редагування шаблону

Форма редагування за структурою нагадує форму додавання шаблону, але її наповнення залежить від того, чи створений шаблон для однієї або для кількох партнерських програм.

- Шаблон для однієї п/п – форма редагування повністю наслідує форму додавання.
- Шаблон для кількох п/п – форма редагування має відмінності у відображенні налаштувань для кожної партнерської програми.

[image: https://d295evyo48.ucarecd.net/2f32afb1-c4d9-4ca5-b90c-bf64d1d961e5/Group_127.png]

У формі редагування можна змінити назву, належність до партнерської програми (за наявності кількох п/п) та умови шаблону.

Поки партнерську програму не обрано, налаштування "За замовчуванням" та "Валюта" залишаються в стані disable.

Якщо під час редагування зняти чекбокс з конкретної п/п (і застосувати зміни), у межах цієї партнерської програми буде видалено шаблон і кастомні офери, створені на його основі.

Умови для видаленого офера припиняють діяти з початку дня.

3.3. Нюанси

Для сторінки "Офери" партнера налаштовано дефолтне сортування, за якого спочатку відображаються офери за замовчуванням, а потім кастомні (всередині застосовано вкладене сортування за датою зміни).

## 4. Видалення шаблону офера

Видалення шаблону офера можливе лише за умови, що він не використовується партнерами.

Якщо за шаблоном офера є хоча б один створений рефкод у межах партнерської програми, цю п/п неможливо зняти під час редагування, оскільки неможливо видалити шаблон офера, який використовується партнерами.

Під час кліку на "Видалити", якщо за шаблоном не створено жодного рефкоду, відображається іконка підтвердження видалення шаблону.

Після підтвердження шаблон видаляється. Кастомні офери, створені на основі такого шаблону, також видаляються.

Якщо шаблон використовується за замовчуванням, спочатку необхідно призначити дефолтним інший шаблон – лише після цього з’явиться можливість видалити поточний.

### 5. Лог змін

Під час кліку на іконку "Історія" відкривається модальне вікно з відображенням історії змін вибраного шаблону оферу.

[image: https://d295evyo48.ucarecd.net/8b0ee4d3-b88c-4df7-aed9-e224107baaf7/AMP_-_Offers_Templates_2025-12-11_15-44-57.png]

Дані, за якими можна відстежити зміни:

- Партнерські програми
- Налаштування "За замовчуванням"
- Назва шаблону
- Умови шаблону

## 6. Кастомні офери, створені на основі шаблонів оферів

На сторінці "Видані офери" у таблиці відображені всі кастомні офери, створені на основі шаблону, із зазначенням їхньої належності до партнера / групи партнерів, а також з описом умов оферу.

[image: https://d295evyo48.ucarecd.net/0d5de238-8b96-4403-8174-ef45a54b14fc/AMP_-_Affiliate_Offers_2025-12-11_15-38-42.png]

## 7. Експорт кастомних оферів

Під час кліку на кнопку "Экспорт" відкривається модальне вікно з налаштуваннями експорту кастомних оферів / шаблонів оферів.

[image: https://d295evyo48.ucarecd.net/90d14f14-8683-4663-9380-2fdb95a13d6a/AMP_-_Offers_Templates_2025-12-11_15-41-14.png]

Експорт можна отримати в браузері ("Експорт") або відкладеним листом на пошту ("Експорт на пошту") – рекомендовано у разі великого обсягу даних.

Під час "Експорту" у браузері, якщо запит занадто великий, буде відображено повідомлення про неможливість виконання операції. У такому випадку варто зменшити період і умови вивантаження або запросити експорт на пошту.

7.1. Нюанси

- Фільтр "Бренд":
○ Якщо в межах пункту "Партнерська програма" нічого не обрано, відображаються всі доступні бренди. Якщо обрано партнерську програму – для вибору доступні лише дозволені бренди;
○ Якщо в межах пункту "Оператор" нічого не обрано, відображаються всі доступні бренди. Якщо обрано оператора – для вибору доступні лише дозволені бренди;
○ Якщо спочатку було обрано бренд, а потім змінилися залежні значення (партнерська програма або оператор), вибір бренду скидається.
- Фільтр "Шаблон":
○ Є залежність від пунктів "Партнерська програма", "Бренд" та "Тип оферу". Якщо в зазначених пунктах обрано значення, шаблони оферів відображаються лише відповідно до вибраних сутностей.

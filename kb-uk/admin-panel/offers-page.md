## 1. Структура сторінки "Офери"

1.1. На сторінці відображається інформація про всі налаштовані офери для конкретного партнера. Кожен офер виведений в окремій картці.

[image: https://ucarecdn.com/2e81fe69-88a7-49d2-9288-1270a50e1790/Снимок_экрана_2025-01-23_в_12.53.39.png]

○ Якщо у партнера немає оферів – виводиться порожня сторінка без оферів.
○ Для партнерів з оферами – виводяться картки оферів.

Додавання офера відбувається через кнопку "+ Додати офер", яка розміщена у верхній частині сторінки на всю ширину.

1.1.1. Зі сторінки "Офери" можна перейти на сторінки: "Профіль", "Офери", "Гравці", "Постбеки", "Статистика", "Тікети", "Мультиакаунти".

З інформаційної плашки можна "Увійти як" під партнером.

1.2. Картки оферів виведені у порядку активності: активні (Active) → заблоковані (Blocked). Усередині групи активності застосовується вкладене сортування за датою зміни (зміною вважається будь-яке редагування офера).

[image: https://ucarecdn.com/f73d26af-63df-4624-bef9-993888d85f4e/Снимок_экрана_2025-03-13_в_17.13.55.png]

Доступна фільтрація/групування оферів за параметрами:

- Бренд
- Тип офера
- Офер
- ГЕО
- Тип трафіку

## 2. Картки оферів

Картка офера відображає основну інформацію про налаштовані умови офера для партнера.

[image: https://ucarecdn.com/bea31a63-a37e-4983-9277-d4dd27777ad0/image.png]

Картка офера містить дані:

- Валюта офера;
- ID офера, його назва з адмін-панелі та бренд офера;
- Назва офера для к/п;
- Адміністратор, який востаннє редагував офер;
- "Початок дії" – параметр показує дату та час активації останніх налаштувань/умов офера;
- Базові та Кастомні умови;
- Інформація про умови Кваліфікації та Декваліфікації;
- Інформація по Rentref;
- Коментар – якщо для офера залишили коментар, виводиться відповідний блок.

2.2. Якщо на офер діє капа – у картці виводиться сповіщення про дію правила капи.

[image: https://ucarecdn.com/dfd07317-ebb9-4854-9fe9-535470175c19/image.png]

Через іконку в сповіщенні можна перейти до правила капи за офером.

Якщо правило капи налаштоване на всі офери партнера, інформація про капу відображатиметься праворуч від кнопки "Активність за оферами".
При кліку на іконку відкриватиметься сторінка з капами тільки для цього партнера.

2.2.1. Якщо для офера налаштовано мін. депозит або рекомендована сума – у картці виводиться інформаційна плашка із заданими умовами.

Також відображається іконка, за якою відкривається сторінка Налаштування min.dep та recommended sum (https://aff.ltd/admin/tds_traffic_scheme/mindep_settings) для партнера.

2.3. Швидке редагування

Умови офера можна відредагувати через іконку "олівець".

Також доступне швидке редагування (без необхідності відкриття форми редагування).

[image: https://ucarecdn.com/3e23c641-4d87-43e1-8a3e-48b6f296ceb4/Снимок_экрана_2025-03-21_в_14.01.55.png]

[image: https://ucarecdn.com/4093012a-6f05-46c8-9354-83453b583694/image.png]

Швидке редагування функціонує за принципом звичайного редагування, але з обмеженим набором полів.
Доступне для всіх типів оферів.

На заблокованих оферах немає можливості швидкого редагування умов. Також це стосується оферів, запланованих до видачі.

## 3. Блокування/Розблокування оферів

Офер можна заблокувати:

- З початку поточної доби
- З 15:00 (UTC+0) – з наступної години

15:00 – змінна часу, в якій завжди відображається найближчий наступний час.

Також можна запланувати час блокування на конкретний момент.

Офери з запланованим блокуванням підсвічені червоною смужкою.

[image: https://ucarecdn.com/1040d5bc-b7dc-4c97-a15c-6041f444bc2f/image.png]

При блокуванні CPA або гібридних оферів з початку поточної доби виводиться інформаційний блок з даними про кількість Qual Count (Web), яких торкнеться блокування офера.

З моменту блокування трафік за офером не буде зараховуватися.

3.1. Заблокований офер

Якщо офер заблоковано – для нього виводиться мітка Blocked.

[image: https://ucarecdn.com/5289d87b-27f2-4829-8f64-61720fe65906/image.png]

Для заблокованого офера іконка "Заблокувати" змінюється на іконку "Розблокувати".

○ На заблокованих оферах немає можливості швидкого додавання та редагування умов.
○ Для заблокованого офера можна налаштувати виведення статистики в к/п. При цьому нарахування доходу не здійснюються.

3.2. Офер можна розблокувати:

- З початку поточної доби
- З 15:00 (з наступної години)

Час вказується за UTC+0.

При розблокуванні офера з початку поточної доби, якщо по оферу був трафік, зміни будуть застосовані до всіх гравців (з початку поточної доби).

## 4. Створення та редагування офера. Планування.

4.1. Додавання офера

Заповнення форми додавання офера залежить від типу налаштовуваного офера. Відмінності полягають у виведених полях для задання умов.

[image: https://ucarecdn.com/6274c71f-b697-4595-81a5-5cd6dee0cb6d/Снимок_экрана_2025-01-23_в_13.04.38.png]

Послідовність заповнення полів для налаштування офера: Бренд → Тип офера → Офер.

- Валюта – за замовчуванням вибрана дефолтна для партнерської програми.
- "Назва в кабінеті партнера" – необов'язкова для заповнення. Якщо значення не заповнено, у к/п буде відображатися назва офера з адмін-панелі. Розмір введеного назви не більше 500 символів.

Нижче заповнюються Базові та Кастомні умови. Ставка за кастомними умовами буде враховуватись для гравців, які підпадають під задані умови.

○ Для RS-оферів за кастомними умовами можна вибрати тільки ГЕО.
○ По Sub_ID можливий ввід кількох значень через кому.

Для CPA, CPFD та гібридних оферів виведені блоки для заповнення умов Кваліфікації та Декваліфікації.

Додаткові налаштування:

- Тип трафіку – вибір серед доступних типів трафіку.
- Rentref – налаштування відповідає за нарахування доходу розробнику за оренду додатку.
- Коментар – опціональне поле. Розмір коментаря не більше 500 символів.

Додавання офера можна запланувати на "З початку поточної доби" або "Вибрати дату".
Для вибору доступні дати, починаючи з завтрашнього дня.

Офер видається партнеру по кнопці "Додати". Якщо офер був запланований до видачі, на сторінці зі всіма оферами буде виводитись сповіщення про його планову видачу.

4.1.1. Флоу додавання/видачі офера описаний у статті (https://help.aff.ltd/uk/admin-panel/offers-page-ng) за посиланням.

4.2. Редагування офера

Форма редагування за структурою нагадує форму додавання офера.
На сторінці виводиться нік адміністратора, який останнім вносив зміни, та дата початку дії офера.

При редагуванні офера можна змінити: базові умови, кастомні умови, умови кваліфікації/декваліфікації, тип трафіку та Rentref.

Оновлені умови можна застосувати:

- З початку поточної доби
- З 12:00 (з наступної години)
- Вибрати дату та час (запланувати редагування)

Для CPA та CPFD оферів зміни по "Кваліфікації", "Декваліфікації", "Типу трафіку" та Rentref не можуть бути заплановані за датою.
Зміни за датою можливі тільки по базовим та кастомним умовам.

Застосування оновлених умов відбувається через кнопку "Зберегти".

4.2.1. Редагування заблокованого офера

На заблокованих оферах немає можливості швидкого редагування умов. Доступне тільки повне редагування через іконку "олівець".

На сторінці є можливість встановити параметр виведення статистики по заблокованому оферу в кабінеті партнера, при цьому нарахування доходу не здійснюються.

[image: https://ucarecdn.com/1a1bf0c6-a774-4a44-82f8-4378e29740ef/Снимок_экрана_2025-03-21_в_18.08.04.png]

При редагуванні заблокованого офера можна змінити умови та задати час розблокування. В зазначений час офер буде розблокований з відредагованими умовами.

4.3. Планування видачі офера

При плануванні видачі офер стане доступним партнеру в к/п на задану дату та час.

У картці такого офера відображається зелена смуга з інформацією про заплановане додавання офера та кнопка "Скасувати".

[image: https://ucarecdn.com/2c16f7a8-02ee-43b7-a735-98dec50357e6/image.png]

При підтвердженні скасування – скасовується запланована видача офера. Подібна логіка застосовується при скасуванні інших запланованих дій.

Для запланованого до видачі офера недоступний функціонал швидкого редагування базових та кастомних умов, а також швидке додавання кастомних умов.

4.4. Планування редагування офера

При плануванні редагування офер буде оновлений на задану дату та час.

У картці такого офера відображається жовта смуга з інформацією про заплановане редагування офера та кнопка "Скасувати".

[image: https://ucarecdn.com/5a9effff-9bd0-4cc4-a417-386bc8297a7f/image.png]

Після інформаційного тексту додатково виводиться стрілочка вниз, по якій розкривається картка з запланованими до редагування умовами.

[image: https://ucarecdn.com/9747bba7-dd77-4abb-b315-86b94eb07b0b/screencast_2025-01-23_13-45-32.gif]

4.5. Планування блокування офера

При плануванні блокування офер буде заблокований і перестане бути доступним партнеру на задану дату та час. Трафік по такому оферу НЕ оплачується партнеру після блокування.

При плануванні блокування дату та час можна вибрати тільки з наступних діб.

У картці такого офера відображається червона смуга з інформацією про заплановане блокування офера та кнопка "Скасувати".

## 5. Історія змін

При кліку на іконку "Історія змін" відкривається модальне вікно з логом змін за офером.

[image: https://ucarecdn.com/872a6d22-f2eb-4b9e-a555-3dd600a8c025/image.png]

Структура карток схожа на відображення всіх оферів партнера, але вони виводяться в порядку змін. В таймлайні додатково відображаються події блокування, розблокування та планування.

Лог змін організовано від найновіших змін до більш старих. Вкінці логу відображається картка офера з умовами при його створенні.

- CREATED – тег створення офера
- CHANGED – тег редагування офера. Також виводиться при розблокуванні офера.
- BLOCKED – тег блокування офера.
Сама картка не виводиться, оскільки офер заблокований, а попередня картка є останнім станом офера.
- PLANNED – тег планування офера.
Картка офера не виводиться.
Для тегу відображається інформація про:
○ Заплановане редагування офера
○ Скасування запланованого редагування
○ Заплановане блокування офера
○ Скасування запланованого блокування

Зміни для кастомних умов аналогічно відображені в лозі.

5.1. Активація перемикача "Показати зміну" дозволяє підсвітити зміни відносно попереднього стану в межах картки офера.

[image: https://ucarecdn.com/c0bdf137-cc05-40ca-8323-3f2e2dce0613/screencast_2025-01-23_13-31-03.gif]

## 6. Умови офера

У картці офера при кліку на іконку "Умови офера" відкривається модальне вікно з умовами офера та можливістю їх копіювання.

[image: https://ucarecdn.com/76e8b4a3-8788-487e-8ddd-61b1bd815df1/Снимок_экрана_2025-01-23_в_13.24.04.png]

У межах модального вікна копіювання умов офера доступні такі параметри:

- Опис – відображає Бренд, Тип (назву офера в к/п) та умови виконання кваліфікації;
- Ставка – ставка CPA, відсоток RS і задані кастомні умови;
- Бейслайн – умови за бейслайном;
- Тип трафіку – вказаний в офері тип трафіку.

[image: https://d295evyo48.ucarecd.net/e5658d05-e9fe-40a4-be56-c587b760b6dd/image.png]

Після натискання на іконку копіювання умови офера повністю копіюються до буфера обміну.

Стан параметрів запам’ятовується для користувача – зберігається останній заданий стан, який застосовується до всіх оферів.

На сторінці "Офери" над доданими оферами є кнопка "Завантажити умови оферів" – при натисканні відкривається модальне вікно з конфігурацією відображення умов. Для всіх оферів умови експортуються у текстовий файл.

[image: https://d295evyo48.ucarecd.net/03409dbb-f46c-4bd9-8ea6-9f551b409130/image.png]

## 7. "Активність за оферами" і "Статистика за офером"

7.1. Активність за оферами

У картці офера при кліку на кнопку "Активність за оферами" відкривається модальне вікно зі статистикою за оферами за останні 14 днів.

[image: https://ucarecdn.com/1922c36a-d20a-405f-8f02-1c7156390817/image.png]

У таблиці виведені офери з метриками:
○ Site: Hosts
○ Reg
○ FD count
○ FD count (Web)

При натисканні на кнопку "Деталі" відкривається сторінка UniversalStats з групуванням за оферами партнера за останні 14 днів.

7.2. Статистика за офером

У картці офера при кліку на кнопку "Статистика за офером" відкривається модальне вікно зі статистикою за конкретним офером за останні 14 днів.

[image: https://ucarecdn.com/80030521-ba28-4bd3-af36-b3104e004da6/image.png]

У таблиці виведені дані для офера по метриках:
○ Дата
○ Site: Hosts
○ Reg
○ FD count
○ FD count (Web)

При натисканні на кнопку "Деталі" відкривається сторінка UniversalStats з групуванням за датою для офера партнера за останні 14 днів.

## 8. "Отримати посилання" на офер та "Копіювати офер"

8.1. "Отримати посилання" на офер

У картці офера при кліку на кнопку "Отримати посилання" відкривається модальне вікно з створеними трекінговими посиланнями за конкретним офером.

У таблиці виведені створені партнером трекінгові посилання:

- Кампанія – виводиться назва кампанії з к/п та посилання для копіювання.
- Тип промо – виводиться тип промо з к/п.

Поруч з кожною кампанією виводиться іконка копіювання. При кліку копіюється тільки партнерське посилання.

Під таблицею виводиться кнопка "Копіювати все". При кліку в буфер обміну повністю копіюється таблиця з збереженням структури.

У стовпці "Кампанія" при наведенні на рядок із назвою з’являється іконка редагування. Після кліку на іконку поле з назвою стає доступним для редагування.

[image: https://d295evyo48.ucarecd.net/79ac2f0b-ccb8-4235-af4a-a34cee22dfd9/screencast_2025-11-13_15-20-26.gif]

Нижче доступна кнопка "Створити посилання" → при натисканні на неї відкривається нове модальне вікно для створення посилання в адмін-панелі. Бренд та оффер уже обрані "під капотом".

[image: https://ucarecdn.com/962b6a06-c6c0-4560-b290-23608f705881/Снимок_экрана_2025-05-15_в_14.11.15.png]

8.1.1. У модальному вікні відображено доступні партнеру промо матеріали.

На етапі вибору промо:

- Якщо вибрано лише 1 промо – відображається кнопка "Створити".
- Якщо вибрано 2 або більше промо – кнопка "Створити" замінюється на "Створити окремо". Між кнопками "Створити окремо" та "Закрити" додатково відображається кнопка "Створити ротатор".
Після вибору "Створити окремо" – для всіх вибраних промо створюються окремі партнерські посилання.

[image: https://d295evyo48.ucarecd.net/47a8c3fc-d15a-431f-9558-4ed5f6fb95e9/screencast_2025-10-16_14-33-01.gif]

Функціонал дозволяє вибрати промоматеріали (один або кілька для ротації), додати Sub_ID/Click_ID, відредагувати назву кампанії.

Чекбокси "Передавати {Sub_ID}" та "Передавати {Click_ID}" увімкнені за замовчуванням. Відповідні GET-параметри додаються до партнерського посилання.

Доступний попередній перегляд промо з адмінпанелі.

[image: https://ucarecdn.com/758d345b-c1f4-4aff-92a4-7188b13ef8e5/image.png]

8.1.2. Створення посилання під кожне промо – "Створити окремо"

У відкритому модальному вікні відображено вибрані промо. Для кожного промо окремо показано його партнерське посилання.

[image: https://d295evyo48.ucarecd.net/da82543d-1f17-4cdc-ae68-0d6ef2d90579/image.png]

Створені в адмінпанелі посилання аналогічно відображаються в К/П на сторінці "Мої посилання".

У модальному вікні передбачено перемикач відображення полів sub_id, sub_id2–5 / click_id: Увімкнути спільні Sub_ID для всіх посилань.

[image: https://d295evyo48.ucarecd.net/939b8dcb-8c31-4df1-ba1a-62b4b81c114a/image.png]

Також доступні поля для введення значень sub_id. Після введення значень вони автоматично додаються до партнерського посилання.

Нижче розташована кнопка "Копіювати інфо всіх кампаній" – відповідає за копіювання в буфер обміну всіх створених посилань.
Копіюються назви та створені партнерські посилання, увесь масив усіх посилань.

8.1.3. У модальному вікні "Отримати посилання" є іконка редагування блоку з "кнопками дій".

[image: https://d295evyo48.ucarecd.net/d5411dcc-2daf-4127-8e90-ed7c9285c725/Снимок_экрана_2025-08-21_в_14.02.52.png]

При натисканні на кнопку відкривається форма редагування промо. На цьому етапі можна додати нові або відредагувати наявні промо для кампанії.

[image: https://d295evyo48.ucarecd.net/4adccb35-e775-4cd0-97ae-c00675fdbafb/screencast_2025-08-21_14-12-58.gif]

При натисканні на кнопку "Створити ще" користувача перенаправляє в модальне вікно "Створити посилання" для вибору промо-лендингів/прямих посилань на той же сайт та оффер, що й раніше. Користувач знову проходить флоу створення посилання.

[image: https://d295evyo48.ucarecd.net/3630e270-af57-43b2-b426-4142e5ec33e0/screencast_2025-08-21_14-19-52.gif]

8.4. Копіювання офера

У картці офера при кліку на кнопку "Копіювати офер" відкривається сторінка зі створенням офера. Функціонал дозволяє перенести налаштовані умови обраного типу офера для нового офера.

За типом офера копіювати умови можна між брендами.

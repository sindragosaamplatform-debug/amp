# Тип партнера: Медіабаєр

Category: ⚙️ Адмін-панель

Summary: Флоу при призначенні типу партнера: Медіабаєр.
Updated: 1 рік тому

Медіабайєр – внутрішній партнер. Статус призначається акаунтам співробітників. Усі нараховані на ці акаунти кошти списуються.

---

Якщо обліковий запис партнера створений для баїнгу або використовується іншим підрозділом компанії для наливки – після створення такого облікового запису необхідно відразу призначити тип вебмайстра: Медіабаєр.

[image: https://ucarecdn.com/4d940c94-d524-498e-8e0d-979d4dd6fa49/image.png]

Важливо! Якщо з якихось причин не призначили тип партнера, то при виявленні такого облікового запису потрібно:

1. Призначити тип партнера: Медіабайер.
2. Перевірити наявність нарахувань. Якщо нарахування почали потрапляти на баланс до поточного місяця – повідомити payment-підрозділу AMP: @goodgirl.
3. Інформація для пейментів: ID партнера, коли був призначений тип баєра, коли відбулося перше нарахування на баланс.

# Ліміт рефкодів (Sub_ID – default)
URL: https://help.aff.ltd/uk/admin-panel/refcodes-limit
Category: ⚙️ Адмін-панель
Section: Промо
Summary: Опис проблеми: при перевищенні ліміту sub_id статистика скидається в default. Ліміт рефкодів.
Updated: 1 рік тому

Значення для sub_id стає default при перевищенні ліміту рефкодів у вебмайстра.

За замовчуванням ліміт динамічних рефкодів встановлений на 10000.

Щоб змінити ліміт, необхідно зайти на сторінку редагування вебмайстра:
https://aff.ltd/admin/new/webmasters/profile/NNNNNN/edit

У пункті Sub_ID limit збільшуємо доступний ліміт.

[image: https://ucarecdn.com/8902eea9-69f1-4582-acb2-f1ac3d422746/Снимок_экрана_2025-03-07_в_16.22.24.png]

Статистика буде перерахована під час наступного добового перерахунку.

# API-фід домену трекінгового посилання в Профілі партнера
URL: https://help.aff.ltd/uk/admin-panel/domain-api-feed
Category: ⚙️ Адмін-панель
Section: Партнери
Summary: Опис використання функціоналу API-фіда актуального домену трекінгового посилання в Профілі партнера.
Updated: 4 місяці тому

API-фід доменів – це посилання, за яким партнер може отримати актуальні домени трекінгового посилання в автоматичному режимі.

Використання API-фіду дозволяє:

- парсити домени без ручного копіювання
- автоматично оновлювати дані у своїх системах

В Профілі партнера, в блоці "Додаткова інформація", доступний блок "Домени партнера". У цьому блоці відображаються всі актуальні домени, які використовує партнер:

- домени (PE) трекінгових посилань
- TDS-домени

Ці дані завжди відповідають поточним налаштуванням і оновлюються при будь-яких змінах.

[image: https://d295evyo48.ucarecd.net/95225fa0-313e-400d-a174-93b44ddf8644/image.png]

За кнопкою "API-фід доменів" є можливість скопіювати API-фід для того, щоб парсити актуальні домени.

[image: https://d295evyo48.ucarecd.net/d84077e7-e2ae-4fb5-a939-f553148fcdf7/image.png]

При переході за посиланням API-фіду відображається поточний активний домен.

[image: https://sc.mmsot.com/demo-fireaff.comapigetActibb8f2d7e1356e75ee35fe46d7647_2026-03-27_11-35-39.png]

Якщо домен змінюється (наприклад, відбувається заміна трекінгового або TDS-домену), він автоматично оновлюється в API-фіді.

Подальше використання API-фіду реалізується на стороні партнера і залежить від його технічних можливостей та використовуваних інструментів.

Наприклад, один з багатьох варіантів – використовувати API-фід у скрипті для автоматичної підстановки актуального домену в посиланнях свого трекера.

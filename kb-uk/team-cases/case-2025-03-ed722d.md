Хочу повернуктись до питання з формулою для параметру bounce rate %
Ми врахували запропонований вами варіант. Проте вирішили накидати ще декілька прикладів з формулами.
Прохання переглянути варіанти з доки, щоб впевнетись в відповідності показників до очікуваних. Та обрати оптимальну формулу під метрику

[посилання]

В стовбцях Bounce Rate % v1 - Bounce Rate % v5 виведені значення для різних варіантів формул:

Bounce Rate % = (Landing: hosts - TDS: unique visits) / Landing: hosts * 100 - в Bounce Rate % v1 запропонований вами вараінт, виділений заливкою
Bounce Rate % = (Landing: hosts - TDS: visits) / Landing: hosts * 100
Bounce Rate % = (Landing: hosts - Site: hosts) / Landing: hosts * 100
Bounce Rate % = (Site: hosts / Landing: hosts) * 100
Bounce Rate % = (TDS: unique visits / Landing: hosts) * 100
Для зручності в коментарях додано опис метрик

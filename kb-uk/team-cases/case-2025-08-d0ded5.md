Якийсь час тому ви писали, що можете допомогти зі створенням скрипту для лендінгу, нам лише потрібно сформулювати запит.

Ми почали більш активно використовувати ось цей:

<script>
if (localStorage.getItem('visited')) {
    location = '{tds}';
} else {
    localStorage.setItem('visited', 1);
}
</script>
Ми використовували його для редіректу юзера, якщо той вже відвідував лендінг.
Проблема в тому, що редірект рахується(наскільки я це зрозумів) по відвідуванню PE домену. Тобто, якщо юзер вже побачив колись лендінг х123, то y456 йому не відкриється, лише відбудеться редірект на вказаний шлях.

Чи можливо допрацювати скрипт таким чином, щоб він працював саме в межах лендінгу ?

Пробуйте такий скріпт:
<script>
    // Унікальний ключ для конкретного лендінга (по шляху в URL)
    const key = 'visited_' + location.pathname;

    if (localStorage.getItem(key)) {
        location = '{tds}'; // редірект тільки якщо цей лендінг вже відвідували
    } else {
        localStorage.setItem(key, 1); // позначаємо, що цей лендінг вже відвідано
    }
</script>

[AMP]:
Так, по всій статистиці в кабінеті виводиться Action stats (це в Редагуванні профілю налаштовується - https://aff.ltd/admin/new/affiliates/profile/[id]/edit)
А по оферам партнера є обмеження для виводу статистики для нього (в кабінеті):
FD для партнера буде виводитись тільки тоді, коли гравець кваліфікується (через тип оферу CPFD)
ще впливає активна умова CPA Entry month - по ній всі гравці, які були зареєстровані не в поточному календарному місяці, не відображатимуться у статистиці партнера, і по RD статистика також.
Ця умова загалом впливає на виведення статистики гравців, які не в поточному місяці зареєструвались, - в по CPA, і по Revshare частинам оферів.
Якщо зараз відключити цю умову - то вже не буде виводитись статистика по тим гравцям, які минулого місяця зареєструвались, "оновлення" статистики для партнера не буде.
В статті детальніше про CPA Entry month описано, і приклад з відключенням: https://help.aff.ltd/uk/admin-panel/entry-month-cpa

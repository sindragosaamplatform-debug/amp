Да, можно передать ##USER_ID## - ID игрока на бренде, макроса для ID депозита (tid) нет к сожалению.

И вопрос по суме депозитов - постбеки отправляются по разным событиям (разные ссылки шаблонов постбеков под каждое событие, например [посилання]):
- отдельно шаблон постбека по FD
- отдельно шаблон постбека по RD

Соответственно, сначала отправляется постбек по FD, далее - постбеки по RD при последующих депозитах игрока.

Для партнера это будет выглядеть так
1 пб - user id - сумма 2$ (FD)
2 пб - user id - сумма 3$ (RD)
3 пб - user id - сумма 2$ (RD)

Для того, чтобы партнер получал пб по RD нужно добавить шаблон постбека на событие RD: [посилання]
Тут важный момент: если CPA/CPFD - то по событию RD после квалификации игрока постбек перестает отправляться.

## Відповідь платформи
[AMP]:
Привет)
Наш продуктовый аналитик проанализировал трафик партнера, у него вышло получить IP.
Действительно по разным базам IP пробивается с разными ГЕО. Такое бывает очень редко с реальными игроками.
С большой вероятностью, такое произошло из-за низкого качества трафика. Очень похоже на ботовый трафик: почти в 100% переходов используется один user-agent, также почти 100% переходов совершены с IP-адресов типа IPv4, принадлежащих одному IP-пулу, что очень нетипично для реального трафика и, наоборот, очень типично для ботового).

а ви можете нам дати список цих ІР, щоб ми зметчили їх з партнером. тут скоріше всього питання до трафік сорса, або вебмайстра, який по класиці жанру замість реальних показів хоче нам накрутити ботові

Аналітик надав файл, що містить список IP та порівняння результатів геолокації IP-адрес із сервісів MaxMind та IP2Location:
ips — список IP-адрес для перевірки.
maxmind — країна, місто, провайдер тощо від MaxMind (всі IP — ОАЕ, XServer).
ip2location — аналогічна інформація від IP2Location (всі IP — Чилі, дата-центри).
vendor — посилання на сервіси для перевірки IP.
Висновок: обидва сервіси дають різні результати для одних і тих самих IP.

В цьому текстовому редакторі немає 11 розміру шрифту, але при копіюванні тексту з іншого джерела зберігається форматування.
Скоріш за все тексти шаблонів листів копіювали з документу, де був налаштований 11 pt шрифт, тому в них воно так і вставилось.
Через це і в Source code не можна змінити розмір шрифту, бо форматування не цього редактору.

Як варіант, що можна зробити:

Зайти в Source code
Скопіювати код, який є (без прописаного розміру шрифту)
Вставити цей код в ChatGPT і і попросити його прописати Font Size
Вставити готовий код з прописаним Font Size в Source code в шаблоні листа
Тоді зміниться розмір тексту, але збережеться все інше форматування)

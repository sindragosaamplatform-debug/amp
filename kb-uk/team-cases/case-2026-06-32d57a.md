Подскажите, пожалуйста, можно ли реализовать следующую логику на стороне оффера

Допустим, минимальный квалификационный депозит для FTD составляет 100 злотых. Если игрок в качестве первого депозита вносит меньше этой суммы, например 70 злотых, то он не проходит квалификацию по FTD

Можно ли сделать так, чтобы такой игрок вообще не отображался в статистике партнера и не учитывался в ней в дальнейшем?

То есть даже если позже этот же игрок внесет еще 500 злотых или любую другую сумму, он все равно не появится в статистике партнера, так как не выполнил условие по минимальному депозиту на своем первом депозите

Есть ли возможность настроить такую механику?

По текущей логике такой настройки оффера нет, чтобы полностью соответствовало такому кейсу.
Тип оффера CPA + Baseline подходит по проверке первого депозита: считается только один платеж (FD), например первый депозит должен быть ≥100 PLN для квалификации; но если игрок сделал FD 70 PLN, он все равно будет виден партнеру в статистике как привлеченный игрок (просто не будет CPA начисления/игрок не будет квалифицирован).
CPFD подходит по части: игрок, который не выполнил квалификацию, вообще не отображается в статистике партнера. Но сама механика другая: baseline (мин. сумма депозитов игрока для квалификации) может выполняться несколькими платежами, не только FD.

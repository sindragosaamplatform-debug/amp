## 1. Загальна інформація

Статистика для партнера доступна в боковому меню Кабінету.

При переході на сторінку партнер може переглядати статистику свого трафіку за доступними параметрами.

Статистику можна групувати за Датою, Брендом (сайтом казино), Офером, Кампаніями, Країнами, sub_id, Лендінгом (ще тут відображаються прямі посилання на головну та форму реєстрації).

[image: https://ucarecdn.com/262006a6-7803-42f2-8d0c-d4187dc8e347/image.png]

Зверху відображається часовий пояс виводу даних і відомості про останнє оновлення статистики.

[image: https://d295evyo48.ucarecd.net/e0296774-815b-4440-a942-97947bbf6a4e/Traffic_Cake_iGaming_Advertiser._Exclusive_Gambling_&_Betting_offers._2025-11-13_11-08-05.png]

Доступні наступні фільтри для виведення статистики: Період, Бренд (сайт казино), Країна, Офер, Трекер sub_id, sub_id, Кампанія.

[image: https://ucarecdn.com/cdf93c4d-c316-400d-9ce0-dd86318fdfc2/image.png]

Якщо у партнера є SUB_ID вищих рівнів (sub_id_2–5), поруч із табом відображається стрілка для відкриття випадаючого списку доступних Sub_ID.

[image: https://d295evyo48.ucarecd.net/4f28c9af-9273-4f97-bb58-ac5c6018795a/screencast_2026-04-02_14-06-00.gif]

Для аналізу трафіка доступні такі параметри статистики (розкрити список можна, якщо клікнути на кнопку "Налаштування статистики").

[image: https://ucarecdn.com/0fbf89cd-c177-4215-b653-71beaabe4e91/image.png]

Якщо у партнера були офери в різних валютах з моменту його реєстрації, йому відображається перемикач валют зліва над таблицею.

[image: https://ucarecdn.com/6c59bf3d-0133-493e-9a88-1172618a8e74/image.png]

При появі статистики за новою валютою біля перемикача з’являється червона крапка. За нею партнер може зрозуміти, що з’явилась нова статистика, яку варто переглянути.

[image: https://ucarecdn.com/da7f6451-7342-48b1-a24b-c8769f46b93e/image.png]

Індикатор зникає після перемикання на відповідну валюту. Крапка відображається лише один раз – до першого перегляду статистики у цій валюті.

## 2. API віддаленої статистики

Для партнера існує можливість отримувати статистику через API - на сторінці доступні посилання у форматі JSON та XML.

[image: https://d295evyo48.ucarecd.net/00cecb80-5bda-4c86-b7d4-e731a0b8d731/image.png]

Метрики для API статистики ПП аналогічні параметрам на сторінці "Статистика" в Кабінеті (задаються на сторінці "Параметри статистики" в адмін-панелі).

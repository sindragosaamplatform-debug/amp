1. Загальна інформація

## Двофакторна аутентифікація (2FA) – інструмент захисту облікового запису від несанкціонованого доступу. 2FA додає додатковий рівень безпеки.
При вході в систему або виконанні важливих дій потрібно підтвердити особу за допомогою OTP-коду.

Доступно два способи підтвердження:

- Email – код надсилається на електронну пошту партнера.
- Google Authenticator (GA) – код генерується у програмі на мобільному пристрої.

Активація 2FA доступна для подій:

- логін до кабінету партнера;
- зміна пароля;
- зміна платіжних реквізитів.

2. Управління загальними налаштуваннями 2FA для партнерської програми в адмін-панелі

## На сторінці створення/редагування партнерської програми доступна опція: "Двофакторна автентифікація".

Шлях: "Параметри" → "Список партнерських програм" → кнопка "Редагувати".

[image: https://d295evyo48.ucarecd.net/b88dbc99-0174-4be8-b5d2-4f099b990b25/screencast_2025-08-07_12-43-29.gif]

Для кожної партнерської програми доступні варіанти налаштування 2FA:

- Обов'язкова для партнерської програми – обов'язкове підключення 2FA всіма партнерами;
- Встановлюється партнером – партнер самостійно приймає рішення про підключення 2FA.

Налаштування використовується одразу після встановлення параметра для партнерської програми.

2.1. Опція "Обов'язкова для партнерської програми"

У разі використання опції "Обов'язкова для партнерської програми" – в кабінеті партнера для всіх користувачів приховується кнопка "Вимкнути" для 2FA.

Партнер НЕ може вимкнути 2FA під час використання опції "Обов'язкова для партнерської програми".

Партнер може вимкнути підтвердження для події "Логін" – інші типи перевірки відключити неможливо.

Для партнера в кабінеті доступна зміна методу 2FA – Email або Google Authenticator.

2.1.1. Логіка для поточних партнерів:

- Для партнерів, у яких активна 2FA, їхній вибраний спосіб (Email або GA) залишається активним – але включається перевірка для всіх подій (логін, зміна пароля, зміна реквізитів).
- Для партнерів, у яких НЕ активна 2FA, система автоматично увімкне 2FA – спосіб Email, при цьому активуються перевірки для всіх подій (логін, зміна пароля, зміна реквізитів).

2.1.2. Логіка для нових партнерів:

- Обов'язкова активація 2FA відбувається після першого додавання платіжних реквізитів. До цього моменту партнер може підключити 2FA добровільно.
- При самостійному підключенні 2FA автоматично активуються перевірки для всіх подій.
- Якщо у партнера не активована 2FA, то при першому додаванні платіжних реквізитів через кабінет буде виводитись модальне вікно з пропозицією підключити 2FA – це обов'язкова умова для додавання реквізитів.
Після успішного налаштування 2FA відбувається збереження реквізитів. Після цього – для партнера активуються перевірки для всіх подій.

Якщо закрити модальне вікно з налаштуванням 2FA – платіжні реквізити не зберігаються.

[image: https://d295evyo48.ucarecd.net/f6487c3d-b20f-4f6b-be26-6f5cdfafe9b4/screencast_2025-08-14_10-32-33.gif]

2.1.3. Логіка активації 2FA при додаванні реквізитів менеджером в адмін-панелі

Якщо менеджер додає платіжні реквізити партнера в адмін-панелі на сторінці "Редагування платіжних реквізитів" – для акаунта партнера автоматично включається 2FA по email на всі події (логін, додавання платіжних реквізитів, зміна пароля).

Умова актуальна, якщо у партнера раніше не було підключено 2FA і для партнерської програми активовано опцію "Обов'язкова для партнерської програми".

[image: https://d295evyo48.ucarecd.net/91999122-a086-464d-b2f7-a4b92714cc72/image.png]

2.2. Опція "Встановлюється партнером"

При використанні опції "Встановлюється партнером" партнер може додати двофакторну автентифікацію самостійно в кабінеті партнера на сторінці Профіль у табі "Керування 2FA" (AffV4) або "Безпека та вхід" (AffPartners_v1).

У цьому вам партнер може активувати 2FA на вибір для:

- логіна до кабінету партнера;
- зміни пароля;
- зміни платіжних реквізитів.

Для відключення 2FA для будь-якої події потрібно також підтвердити цю дію за допомогою введення коду, отриманого на Email або GA (залежно від підключеного методу 2FA).

2.2.1. Нюанси підтвердження зміни платіжних реквізитів через email та 2FA (при активній опції "Встановлюється партнером"):

- При відключеній 2FA під час додавання/редагування платіжних реквізитів у профілі партнеру потрібно підтвердити дію через email.
Варто враховувати, що 2FA та підтвердження зміни реквізитів через email – взаємозамінні функціонали:
○ При включенні 2FA – підтвердження через пошту відключається;
○ При відключенні 2FA – логіка підтвердження через пошту працює назад.
- Логіка блокування виплат залежить від налаштування "Зміна реквізитів партнером":
○ Якщо для партнера встановлено, що блокування має створюватися, то після підтвердження реквізитів у рамках модального вікна 2FA створюється блокування виплат;
○ Якщо для партнера встановлено, що блокування НЕ створюється, то після підтвердження платіжні реквізити активні та блокування немає.
- Якщо активовано підтвердження через 2FA, відключається логіка, що адміністратор може підтвердити зміну реквізитів за партнера в адмін-панелі (на сторінці "Редагування платіжних реквізитів").

2.3. Нюанси при заміні опції "Обов'язкова для партнерської програми" на "Встановлюється партнером":

- для всіх партнерів, які реєструються після перемикання налаштування, при додаванні реквізитів немає обов'язкової активації 2FA;
- при додаванні платіжних реквізитів через адмін-панель НЕ вмикається 2FA по email;
- для всіх вже зареєстрованих партнерів продовжує бути активованою 2FA;
- стає доступною можливість відключення 2FA через к/п;
- якщо партнери не входили до системи під час дії опції "Обов'язкова для партнерської програми", 2FA для них не буде активовано автоматично, оскільки умова додавання застосовується лише в момент логіну до кабінету.

3. Управління 2FA для партнера через адмін-панель

## На сторінці "Редагування" у профілі партнера в блоці "НАРАХУВАННЯ І БЕЗПЕКА" доступний параметр "2FA для партнера" ​​з можливістю активувати/деактивувати 2FA для конкретного партнера.

[image: https://d295evyo48.ucarecd.net/751d5ca0-5317-49f1-893b-e6c00f7938f5/AMP_-_[226888]_Webmaster_Profile_2025-08-12_17-32-01.png]

3.1. При активації 2FA для партнера за замовчуванням встановлюється 2FA через Email. Також автоматично вмикається параметр "2FA при логіні".

[image: https://d295evyo48.ucarecd.net/21d3efd9-0b33-4deb-9795-d972942e5e32/image.png]

При активованій 2FA по email доступна можливість скидання ліміту запитів на 2FA по email (доступно 5 запитів) – 2FA email limit.
Після скидання партнер знову зможе зробити 5 запитів.

Термін життя OTP-коду, отриманого на Email, – 3 хвилини.

3.2. У параметрі "Зміна способу 2FA" можна переключити 2FA на спосіб Google Authenticator. При зміні методу стає доступним параметр скидання 2FA Secret.

[image: https://d295evyo48.ucarecd.net/2ed56ac0-0af8-4110-973f-7e29d7c4c9b6/image.png]

При скиданні 2FA Secret новий secret генерується користувачем за наступного логіну в кабінет партнера (ініціюється повторне налаштування 2FA за допомогою Google Authenticator).

[image: https://d295evyo48.ucarecd.net/eedc0a30-174e-4095-92ef-82c42b0c87e9/2fa-new.gif]

3.3. У разі активної опції "Обов'язкова для партнерської програми" неможливо відключити 2FA для партнера в адмін-панелі, доступне лише перемикання методу 2FA – Email або Google Authenticator.

[image: https://d295evyo48.ucarecd.net/f4067ed9-e464-4a59-9b4b-e66a14f1e2c8/image.png]

4. Процес самостійного підключення 2FA у Профілі к/п (на прикладі Google Authenticator)

- При натисканні на кнопку "Увімкнути" відображається модальне вікно з вибором способу автентифікації – Email або Google Authenticator.

[image: https://d295evyo48.ucarecd.net/2d09124f-04fd-49b1-b42d-0bdb1ebb1f0e/22.gif]

- Після вибору варіанта GA виводиться вікно із пропозицією завантажити Google Authenticator. Доступно для App Store та Google Play.

[image: https://d295evyo48.ucarecd.net/ffb1914b-6c8b-4d9d-a628-85ad4cf9d61f/screencast_2025-08-14_10-45-00.gif]

- На наступному етапі партнеру відображається інструкція з налаштування. У Google Authenticator можна відсканувати отриманий QR-код або ввести код, що виводиться вручну.

[image: https://d295evyo48.ucarecd.net/0fdf8e3f-9e96-4785-ba6e-4641a4835b41/666.gif]

- На завершальному кроці відображається форма верифікації коду OTP. Потрібно ввести код із 6-ти символів із застосунку.

[image: https://d295evyo48.ucarecd.net/8df24e4c-6914-4cd9-bdef-e7dd1bcf6e84/777.gif]

- Після підключення Google Authenticator у параметрах таба "Керування 2FA" будуть виводитися доступні події для активації перевірки 2FA.
Наприклад:
○ Якщо користувач активував подію "Логін", то у формі логіна другим кроком буде виводитись форма для введення коду підтвердження.
○ Якщо користувач активував подію "Зміна пароля", то при зміні пароля додатково відображатиметься модальне вікно для підтвердження 2FA.

[image: https://d295evyo48.ucarecd.net/5c19d5d8-86c5-4a21-a48e-bf02f06ef434/image.png]

- При відключенні 2FA будь-якої події (наприклад, "Зміна пароля") відкривається вікно введення коду 2FA.
Це правило поширюється при вимкненні кожного параметра. Дія відключення виконується після дод. підтвердження.

[image: https://d295evyo48.ucarecd.net/55d5b29a-de74-47bf-af9d-59ee29e7c33f/888.gif]
